# VayuCare — GenAI Family & Community Smog Assistant

## Overview
VayuCare is a GenAI-powered civic health and sustainability assistant designed to help families and urban communities navigate severe winter smog and high-AQI episodes.

## Key Features
1. **Hyper-Local AQI & Family Profiler**: Calibrates recommendations based on city/neighborhood AQI, PM2.5/PM10 levels, vulnerable household members (toddlers, elderly, asthma), and housing ventilation.
2. **GenAI Three-Pillar Advisor (Gemini API)**:
   - Low-Emission Daily Routines (aligned with winter thermal inversion windows)
   - Indoor Air Quality (IAQ) Hacks (DIY HEPA/Corsi-Rosenthal filters, wet mopping, window sealing)
   - Sustainable Community Alternatives (carpooling, biomass composting, clean heating)
3. **Quantified Direct Impact Explainer**: Every recommendation shows measurable % PM2.5 exposure reduction and kg CO2e saved.
4. **Interactive Exposure & Emission Simulator**: Real-time gauges tracking indoor PM2.5 reduction and Respiratory Shield Score.
5. **Community Smog Watch Hub**: Crowdsourced hyper-local pollution reporting and neighborhood clean-air pledges.

## Tech Stack & Repo Size
- Lightweight Single-File HTML5 + Tailwind CSS + Vanilla JS + Gemini API (< 50 KB total repo footprint).
